# real-estate-expert-system
Интеллектуальная экспертная система подбора коммерческой недвижимости для малого бизнеса
## Описание проекта

Система заменяет живого риелтора-эксперта: пользователь вводит сферу бизнеса,
бюджет и пожелания, а система на основе базы знаний, нечёткой логики и
машинного обучения выдаёт рекомендацию с объяснением.

Отличие от Циан / Авито:система не просто фильтрует объекты,
а рассуждает как эксперт — советует район, тип помещения и площадь,
объясняя, почему выбран именно этот вариант.

## Цель проекта

Разработка интеллектуальной экспертной системы поддержки принятия решений
при подборе коммерческой недвижимости для малого бизнеса.

## Технологии

- Java — основной язык
- Jess / Drools — экспертное ядро (продукционные правила)
- jFuzzyLogic — нечёткая логика
- Weka — машинное обучение
- Apache OpenNLP — обработка естественного языка
- Spring Boot — веб-интерфейс
- PostgreSQL — база данных

## Структура проекта
src/
├── knowledge_base/ — база знаний (правила)
├── inference/ — механизм логического вывода
├── fuzzy/ — нечёткая логика
├── ml/ — ML-модуль (Weka)
├── nlp/ — NLP-модуль (OpenNLP)
├── gui/ — веб-интерфейс
└── utils/ — вспомогательные модули

data/
├── dataset.arff — датасет для Weka
└── rules/ — файлы правил

docs/
├── architecture.md — архитектура системы
└── ontology.md — онтология предметной области
